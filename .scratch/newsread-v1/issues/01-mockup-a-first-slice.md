# 01: Mockup A：第一個切片和判斷相關的畫面

**What to build:** 畫出第一個切片和判斷相關畫面的 HTML mockup，給使用者確認後才開始做對應的 UI。範圍：今日焦點；閱讀器（原文 / 中英對照、分類側欄：重要度、理由、帶出處的重點、「AI 推論」標示、快速判斷的 8 個按鈕、揭露前遮住 AI 看法的狀態）；追蹤對象管理（五種類型、代號、別名、基準、代號的最新收盤）；貼連結和匯入失敗的畫面；設定（Telegram 配對碼、RSS 清單、每種任務的模型、簡報時間、安靜時段）；Telegram 訊息格式（每日簡報、即時推播、盲測、盲測揭曉、到期提醒）。

**Blocked by:** None (can start immediately)

**Status:** ready-for-agent

- [ ] 每個畫面一個可以直接用瀏覽器打開的 HTML 檔，放在 repo 的 mockup 資料夾
- [ ] 用假資料，涵蓋空狀態、載入中、失敗狀態
- [ ] 桌機寬度和窄視窗都能看
- [ ] Telegram 訊息用接近真實的字數模擬，每日簡報 10 分鐘內看得完
- [ ] 盲判和盲測的畫面在揭露前看不到 AI 的重要度、理由，也沒有依重要度排序的線索
- [ ] 使用者明確核准，核准日期和修改意見記在這張 ticket 裡
