# 08: 非 PDF 的段落內容

**What to build:** 讓沒有 PDF 的資料（純文字、網頁正文）也能成為一則可閱讀的資料，作為新聞、X、Substack、逐字稿的共同基礎。

**Blocked by:** 04（移除研究工作區、文獻搜尋、Zotero 與批次匯入）

**Status:** ready-for-agent

- [ ] 可以從純文字建立一則資料，ID 不依賴 PDF 的雜湊值
- [ ] 正文切成段落，每段有穩定的 ID；同樣的內容重新匯入時 ID 不變（測試）
- [ ] 閱讀器的顯示、劃線、邊注、筆記、問 AI 都能用在沒有 PDF 的資料上
- [ ] 翻譯以段落為單位分批，中斷後可以接著做（用假 AI 引擎測試）
- [ ] 沒有 PDF 時不顯示原頁面板
- [ ] 原文之後被修改時存成新版本，舊版本保留
- [ ] PDF 的匯入和翻譯，既有測試全過
