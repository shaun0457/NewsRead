# 08: 非 PDF 的段落內容

**What to build:** 讓沒有 PDF 的資料（純文字、網頁正文）也能成為一則可閱讀的資料，作為新聞、X、Substack、逐字稿的共同基礎。

**Blocked by:** 04（移除研究工作區、文獻搜尋、Zotero 與批次匯入）

**Status:** done

- [x] 可以從純文字建立一則資料，ID 不依賴 PDF 的雜湊值
- [x] 正文切成段落，每段有穩定的 ID；同樣的內容重新匯入時 ID 不變（測試）
- [x] 閱讀器的顯示、劃線、邊注、筆記、問 AI 都能用在沒有 PDF 的資料上
- [x] 翻譯以段落為單位分批，中斷後可以接著做（用假 AI 引擎測試）
- [x] 沒有 PDF 時不顯示原頁面板
- [x] 原文之後被修改時存成新版本，舊版本保留
- [x] PDF 的匯入和翻譯，既有測試全過

**Notes（2026-11-12）：** 實作在 `easyread/textitem.py`，格式寫在 `docs/data-format.md`「沒有 PDF 的資料」。一段算一頁，翻譯走既有的補譯文流程，每批 12 段。還沒做：已經有譯文的段不能叫模型重譯；原文是中文的文章照樣會送翻譯（ticket 11 決定）；標題區的「全文 N 頁」等文字對段落還寫「頁」。
