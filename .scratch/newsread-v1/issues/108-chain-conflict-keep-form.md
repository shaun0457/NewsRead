# 108: 版本衝突時保留表單內容

**What to build:** 另一個分頁先存了新版本、送出被擋時，保留表單裡打的內容，提示有新版，讓使用者比較後再送。來源：PR #74 SCOPE Q3。（使用者 2026-11-28 決定照建議做）

**Blocked by:** —

**Status:** in-review

- [x] UI 先做 mockup 給使用者確認（2026-11-28 核准）
- [x] 被擋後表單內容還在（測試）
- [x] 可以看新版、比較後重送（測試）

## 做法

- 只改前端（`easyread/web/js/theme/chain.js`）。新增或修改一環時回 400 `field: base_version`：表單和草稿留著，讀新版當底；上方黃色提示「另一個分頁已經存了新版本（vN）」和「看新版」「用我的內容重送」「放棄我的，改用新版」。
- 正在改的那一環在新版裡是哪一環：同一個位置、從和到一樣就是它；不然找從和到一樣的唯一一環；找不到（被移除、改了從或到、有好幾個一樣的）就改成新增，提示裡說重送會加成新的一環。
- 「看新版」打開並排比較（新版 / 我的內容，不一樣的欄位上底色，窄螢幕上下排）；收起時用 `hidden="until-found"`，頁內搜尋找得到。
- 讀不到新版時留在舊版、表單照留，下次重送再試。
- 確認、移除、領漲 / 補漲、定稿被擋時照舊：提示已重新載入。
