# 11: 貼新聞連結匯入並閱讀原文

**What to build:** 使用者在文獻庫貼上一則新聞連結，就得到一則可以閱讀的資料。

**Blocked by:** 01（Mockup A：敘事看板、題材頁和第一個切片的畫面）、08（非 PDF 的段落內容）、09（對外抓取規則與測試替身）、10（帳本與索引核心）

**Status:** ready-for-agent

- [ ] 貼新聞連結之後得到：標題、媒體、正文、發布時間和它的來源（頁面 metadata / 使用者輸入 / 不明）、抓取時間、原始連結、內容雜湊
- [ ] 網址正規化（去掉追蹤參數、AMP 版），同一篇不會重複匯入（測試）
- [ ] 失敗時顯示原因類別，可以改成手動貼全文
- [ ] 被付費牆擋住、只抓到預覽時標示「只有預覽」
- [ ] 每則資料自成一個 Story；無法確定發布時間時標「時間不明」
- [ ] 用 fixture 測試至少 3 種不同版型的新聞頁
- [ ] 畫面符合已核准的 Mockup A
