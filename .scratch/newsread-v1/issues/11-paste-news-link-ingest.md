# 11: 貼新聞連結匯入並閱讀原文

**What to build:** 使用者貼上一則新聞連結，就得到一則可以閱讀的資料。入口有匯入頁、任何頁面右上角的「＋ 貼網址」，以及不在輸入框時直接按 Ctrl+V；全部呼叫同一個 Ingest。

**Blocked by:** 01（Mockup A：敘事看板、題材頁和第一個切片的畫面）、08（非 PDF 的段落內容）、09（對外抓取規則與測試替身）、10（帳本與索引核心）

**Notes（2026-11-12）：** `easyread/ingest.py` + `POST /api/ingest`（docs/api.md 4.65）；前端是共用的對話框 `web/js/common/ingest.js`，文獻庫、閱讀器、追蹤對象頁都有「＋ 貼網址」。和 Mockup A 的差別：做成對話框而不是獨立頁面；進度只列「網址正規化 → 抓取頁面 → 抽出正文 → 建立資料」，沒有「分類 / 翻譯」兩步（那兩步是之後的 ticket）。
- 發布時間記了就不改：手動貼全文時填了不同的時間回 400；原本時間不明（或舊值不合格）的就補上。Story 的時間一律照存好的 meta 走（`textitem.create` 的 `prepare` 在寫入鎖裡處理），帳本和資料不會各說各話。
- 解析有上限：巢狀深度 `MAX_TAG_DEPTH`、標籤數 `MAX_EVENTS`、JSON-LD 個數 / 大小 / 物件數、名稱欄位深度；頁面太長就截到一則資料收得下的量並標 `truncated`。沒寫 `</p>` 的頁面照 HTML 規則自動結束段落。
- 錯誤只回類別和固定訊息；沒預期的錯誤回 500 `internal`，log 只記例外類型。
- Review：python 3 輪（第 1 輪 2 HIGH：省略 `</p>`、補貼全文蓋掉 meta；第 2 輪 1 HIGH：內容沒變時 meta 和 Story 時間不一致，換做法重寫）、typescript 3 輪（第 1 輪 2 HIGH：手動表單送出失敗就不見、關閉後焦點留在看不見的輸入框；第 2 輪 2 HIGH：拿掉 `dialog-backdrop` 讓各頁看不到對話框、關掉重開卡在忙碌）、security 2 輪（2 MEDIUM：解析器 CPU、RecursionError 原文外洩）。都已修並驗收。
- 沒做（LOW / 留給之後）：段落裡的連結照樣變成外部連結、段落裡的 `$` 會被 KaTeX 處理；舊 CPython 的 HTMLParser 遇到沒關的 `<!--` 可能是二次方（有 5 MB 上限擋著）；資料本身壞掉（舊 meta 時間不合格、Story 卻有別的合格時間）時補時間後兩邊會不同；對話框開著時 Ctrl+Tab / Ctrl+W 放行給桌面版換分頁、關分頁。
