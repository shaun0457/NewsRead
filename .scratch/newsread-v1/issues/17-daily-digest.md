# 17: 每日簡報

**What to build:** 每天早上在 Telegram 收到依題材和論點整理的重點。

**Blocked by:** 14（AI 分類寫進帳本）、16（Telegram bot）、58（AI 起草題材頁）

**Status:** ready-for-agent

- [ ] 每天在設定的時間送出（預設 07:30，Asia/Taipei）
- [ ] 依題材整理：哪些論點今天多了加強或削弱的證據、階段有沒有變化；沒有論點的重要資料另列；有字數上限，10 分鐘內看得完
- [ ] 每一點都附原文連結
- [ ] 錯過發送時間（例如電腦關機）時，開機後補發並註明是補發（用假時鐘測試）
- [ ] 簡報裡顯示了 AI 看法的資料，都寫一筆揭露紀錄
- [ ] 畫面符合已核准的 Mockup A
