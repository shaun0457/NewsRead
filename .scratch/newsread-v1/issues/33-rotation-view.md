# 33: 相對強弱排名與相對輪動圖

**What to build:** 用歷史資料看題材和產業的輪動。

**Blocked by:** 32（題材籃子）

**Status:** ready-for-agent

- [ ] 題材籃子和產業相對大盤的強弱排名（1 週、1 個月）
- [ ] 相對輪動圖：相對強度、相對動能，以及最近幾週的移動軌跡（用 ECharts）
- [ ] 算法自己實作，平滑和標準化的參數寫明在畫面說明裡
- [ ] 回推的籃子有標示
- [ ] 一打開就能用歷史資料，不用等資料累積
- [ ] 純函式測試（用合成的價格序列）
- [ ] 畫面符合已核准的 Mockup B

**開放問題（2026-11-15，從 #59 移過來）：因果鏈上公司的「領漲 / 補漲」建議怎麼算。** #59 先放了一個暫用規則（題材第一個版本以來的報酬，不低於同一條鏈公司的中位數 = 領漲），但行情接上前一律 unknown，使用者也還沒決定要不要用它。已知的問題：
- 起點是「我開始寫這一頁」的時間，不是題材真正開始的時間。
- 只跟同一條鏈的公司比，一定有一半被叫領漲；大家漲得一樣多時也硬拆。
- 「補漲」在台股的用法是「同一個題材、基本面也受益，但股價還沒跟上，之後可能追上」，是往前看的標籤，不只是「漲得比較少」。
做這張時跟使用者一起定：建議用相對題材籃子（#32）的相對強弱，例如領漲 = 題材起漲初期相對強度最先轉強、最高；補漲 = 營收占比有出處、但相對強度還低的公司。定好之後改 `easyread/chain.py` 的 `suggest_roles`，以及 `docs/api.md` 因果鏈小節。
