# 37: 我的快速判斷

**What to build:** 使用者在桌機上點一下就完成一筆快速判斷（對論點或追蹤對象），系統依揭露紀錄自動判定是不是盲判。

**Blocked by:** 15（今日新聞頁）、57（題材與論點的資料模型）

**Status:** ready-for-agent

- [ ] 閱讀器、題材頁和今日新聞上可以點一下完成快速判斷。對論點 8 個按鈕：加強低 / 中 / 高、削弱低 / 中 / 高、有關但不改變、無關；沒有對應論點時用追蹤對象的 8 個按鈕：雜訊、中性、偏多低 / 中 / 高、偏空低 / 中 / 高
- [ ] 寫進帳本；`blind` 依揭露紀錄自動判定，揭露之後才做的判斷一定是 false（測試）
- [ ] 有「先判斷」模式：判斷之前不顯示 AI 的看法
- [ ] 判斷之後顯示 AI 的看法和理由
- [ ] 事後補判自動標示
- [ ] 要修改判斷只能新增修正紀錄
- [ ] 畫面符合已核准的 Mockup A
