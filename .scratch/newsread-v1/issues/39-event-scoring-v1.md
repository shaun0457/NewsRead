# 39: 事件打分 v1

**What to build:** 自動算出事件的異常報酬、新資訊判定和各期間結果，並為快速判斷打分。

**Blocked by:** 20（Story 合併與舊聞判斷）、30（行情）

**Status:** ready-for-agent

- [ ] 用市場調整模型和還原股價算異常報酬，分別減掉基準指數和產業指數
- [ ] 新資訊判定：事件窗 [0, +1] 的累積異常報酬，對比事件前 60 個交易日的標準差；或成交量對前 20 日均量的倍數。門檻是參數
- [ ] 期間：1、5、21、63 個交易日
- [ ] 快速判斷自動打分：偏多 / 偏空看方向；中性看絕對值是否低於門檻；信心換算成機率算 Brier score
- [ ] 以 Story 為單位，不重複計分
- [ ] 缺資料的期間標「無法打分」，不當成錯
- [ ] 收盤後和非交易日的事件日規則；美股夏令時間（測試）
- [ ] 只用 `recorded_at` 之後的價格（測試）
- [ ] 除權息日不會出現假的異常下跌（測試）
- [ ] 每次計算都記錄打分方法的版本，舊版本的結果保留
- [ ] 結果顯示在閱讀器的分類側欄
- [ ] 畫面符合已核准的 Mockup A
