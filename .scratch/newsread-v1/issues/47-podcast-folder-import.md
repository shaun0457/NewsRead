# 47: Podcast 逐字稿資料夾匯入

**What to build:** 從本機資料夾匯入 Podcast 逐字稿（例如股癌），每集用發布時間當作時間點。

**Blocked by:** 14（AI 分類寫進帳本）

**Status:** ready-for-agent

- [ ] 在設定裡指定逐字稿資料夾，每集一個檔案匯入
- [ ] 先確認每集發布日期從哪裡取得（檔案內容、檔名或 RSS），結果記在這張 ticket 裡；無法確定的標「時間不明」
- [ ] 建立 KOL（Voice），例如股癌
- [ ] 重複匯入不會重複建立
- [ ] 大量匯入有批次上限和進度顯示
- [ ] 全部匯入前先顯示 AI 費用預估，使用者確認後才開始
- [ ] AI 分類照做，但全部標成事後補判
