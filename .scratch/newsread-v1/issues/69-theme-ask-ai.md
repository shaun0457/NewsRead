# 69: 題材頁問 AI

**What to build:** 使用者在題材頁拿這個題材的剪報夾問 AI，例如「現在進展到哪？還缺什麼證據？」。AI 只根據已經掛在這個題材下的證據、定稿的論點和相關概念卡回答，呼叫一次，不上網，也不自己決定去讀什麼（那是 v2 的 agent 架構）。

**Blocked by:** 10（帳本與索引核心）、12（文章中英對照）、14（AI 分類寫進帳本）、58（AI 起草題材頁）

**Status:** ready-for-agent

- [ ] 送進去的證據只有已經掛在這個題材下、而且已經揭露過的；使用者還沒判斷過的新資料不放（測試）
- [ ] 證據超過上限時用固定規則挑：A、B 級優先，再依日期由新到舊，上限〔預設〕20 則，另有 token 上限（碰到上限的測試）
- [ ] 實際送進去的清單寫進 ContextManifest，畫面可以點開看
- [ ] 回答分「已經確認的 / 還不確定的 / 剪報夾裡沒有的」，每句附出處；引述不在原文就不顯示；推論標「AI 推論」
- [ ] 問到股價或買賣時不給建議，改引導到「市場怎麼回應」或寫成預測
- [ ] 輸入框貼網址時，先問要不要匯入並掛到這個題材；匯入後關係判斷一樣先遮住
- [ ] 回答可以逐句標「正確 / 錯誤 / 編造」，進 golden set；存成筆記、寫成預測
- [ ] 寫 AI 用量；用假引擎測試
- [ ] 畫面符合已核准的 Mockup A（`theme.html` 的問 AI 區）
