設計規則

  1. 先看故事，再看新聞，最後才看股價。首頁是題材和論點；新聞是證據；股價在「市場怎麼回應」，也是「市場在動，原因不明」的觸發。
  2. 先判斷、再看 AI。對論點的盲判在揭曉前看不到 AI 的判斷；直接看會寫揭露紀錄，之後就不算盲判。
  3. 雜訊是相對的。永遠寫明「相對於哪個論點、哪個時間尺度」。AI 判雜訊、而相關概念你還不懂時，先提醒你看概念卡。
  4. 每一句看得出有沒有出處。有出處附 ¶ 或來源；沒有的標「AI 推論」或「AI 解釋」；因果鏈的推論環節用虛線，不能進定稿，除非你確認。
  5. 營收占比只引用來源；階段只依訊號。AI 不估占比，也不憑文字判斷階段。
  6. 草稿不蓋定稿。AI 起草的題材頁、概念卡都要你確認；草稿和定稿都保留版本。
  7. 證據分等級。A 公司公告 / 財報 / 法說會 · B 具名媒體 · C KOL / 分析師 · D 未證實。只有 C、D 的論點標「缺第一手確認」。
  8. 顏色分誰說的。青色 = AI，赭色 = 你；加強 / 偏多用綠，削弱 / 偏空用紅。
  9. 每頁都有空、載入、失敗；桌機和窄視窗都能用。失敗只顯示錯誤代碼和固定說明。
