# 股癌怎麼分析一個題材：給「敘事頁」用的模板研究

> 2026-11-11。目的：NewsRead 要改成以「題材 → 論點」為核心（使用者否決了「新聞 → 多空 → 股價」的 Mockup A），
> 先看謝孟恭實際怎麼講一個題材，再決定敘事頁要有哪些欄位，而不是我自己猜。

## 觀察到的分析結構

| # | 步驟 | 他怎麼做（出處） | 對 NewsRead 的意思 |
|---|---|---|---|
| 1 | **起點常常是盤面，不是新聞** | 「盤面上有一些新的故事跑出來……我注意到市場有一些變化，所以我就會立刻去找說那有可能是什麼東西造成這樣的變化」（EP619）；CPU 是先看到 ARM、Intel、AMD「相對比較硬」，「有可能他們就是帶有一些故事性」（EP650） | 股價不只拿來對答案，也是**觸發**：某個族群相對轉強、但還沒有對應的敘事時，要提示「市場在動，原因不明」 |
| 2 | **講清楚故事的主因，用白話類比** | GPU 是「很強的球員」，CPU 是「教練……指揮調派」；Agentic AI 讓 CPU 用量「甚至可能會過半」（EP650） | 敘事頁第一段是給新手的白話解釋，附一個類比 |
| 3 | **用第一線說法確認，而不是只看技術或論述** | Lisa Su、Intel CFO 說 Xeon 6 產能 “absolutely constrained”、Jensen 說會有更多獨立 CPU 部署，「看了一下御三家就可以確定說 CPU 的 trend 絕對是正確的」（EP650）；Andy Jassy 說客戶想包下 Graviton 但「我們自己都不夠用」（EP652） | 證據要分等級：公司管理層 / 財報 / 訂單 > 媒體報導 > KOL > 「小作文」。法說會、股東信是確認用的關鍵來源 |
| 4 | **警告看太早、過度美化** | 「股票宅很多時候會過度地 sugar coat……你看的是未來的某一種 RD Roadmap……你看得太早」；量子電腦的例子（EP650） | 論點要標**時間點**：現在就放量，還是 roadmap。只有 roadmap 的論點不能算「已確認」 |
| 5 | **從 top-down 走到 bottom-up** | 「本來的考察是比較偏向是 top down……現在開始我們有一些 bottom up 的 feedback 回來了」，例如銅箔廠、銅箔基板廠有明確的衛星料號放量（EP631） | 階段的判斷依據之一：有沒有出現上游料號、訂單、營收的實證 |
| 6 | **受益環節看營收占比，不是「有沾到邊」** | 「你有題材沒有用……我們其實很著重的一點叫做營收的占比」，舉旺宏 NOR Flash 為例：產品到處都有，股價卻沒動（EP631）；查 MEIKO 官網，拆穿「合資廠是要出衛星」的小作文（EP631） | 因果鏈上的每家公司都要有「這個題材占營收多少」，不知道就寫不知道。這也是新手最容易被騙的地方 |
| 7 | **領漲股 vs 補漲股** | 「率先動的那幾支一定就是最後可能會漲最大的」；去找還沒動、跟 SpaceX「有牽到邊」的股票「會比較稍微的危險一點」（EP631） | 籃子裡要分出領漲和補漲；補漲股大量出現是擴散後段的訊號 |
| 8 | **第二層效應：外溢、排擠、轉嫁** | cSSD 漲幅超過 eSSD、毛利最好的是 DRAM 而不是 HBM（EP650）；高階產能排擠，DDR4、DDR3「雞犬升天」（EP604）；銀價上漲讓被動元件漲價，而且「漲上去之後……很難下來」；網通廠客戶如果是 B 端就轉嫁得出去，不一定是受害股（EP631）；CPU 缺貨可能讓 Socket 等元件和 GPU 搶料（EP654） | 敘事除了主鏈，還要有「意外受惠 / 受害」這一欄。這正是 AI 最可能幫上新手、也最可能編故事的地方 |
| 9 | **階段與估值** | 題材「會先……走在比較前面……大家去做一個預期的投射」，估值乘數「先拉滿……再慢慢去下修看看 EPS 是不是真的可以開得出來」（EP619）；新市場的 TAM 常被低估（Uber 例，EP619）；「波段可能是兩年或三年，過程之中可能還是會出一些 20%、30% 的修正」（EP631）；「射出段，就不一定會百分之百跟基本面連動，有時候它是籌碼或是技術面的一個博弈」（EP604） | 階段要有名字和可量的訊號，不能讓 AI 憑感覺判斷（見下方模板） |
| 10 | **利多推不上 ≠ 利多出盡** | 「為什麼股價還沒有漲，是不是利多出盡……沒有，我覺得是因為前面真的漲很多」（EP673） | 對好消息的反應變弱是一個可記錄的訊號，但解讀要謹慎。這很適合做成盲判題 |
| 11 | **下車條件以價格為主** | 「沒有辦法在新高繼續進攻的東西，至少以交易的角度……讓他去做回檔，然後你就休息吧」（EP633）；「破線……爆大量跌破，其實這個對我們來講，就是一個你一定要減碼的地方」（EP593） | 推翻條件分兩種：**論點被推翻**（基本面）和**交易上該下車**（價格）。兩者分開記 |
| 12 | **交易和投資分開** | 「投資呢你就盡量不要去做這種追高的事情……如果你要去做交易的話，可是你套在那邊算基本面的話那你也是在自欺欺人」（EP619） | 對應 spec 已有的「賺什麼錢」（edge）。每個論點要標它是哪一種 |
| 13 | **用真錢驗證想法** | 「我們會有一個想法，這個想法我們會用真金白銀到市場裡面去做驗證……如果對的話就會持續去做加碼」（EP652） | NewsRead 的替代品是預測帳本 + 對答案。使用者是新手，不建議照搬「用真錢實驗」 |
| 14 | **健康多頭 = 族群輪動** | 「多頭就是很多頭……各種類股在那邊輪動，這就是一個很健康的多頭」（EP652） | 輪動視圖是首頁的「市場背景」，不是獨立的分析工具 |

## 由此得到的敘事頁模板（草案）

**題材**（例：低軌衛星）
1. **一句話故事 + 白話類比**：給新手看的。
2. **怎麼開始的**：市場先動，還是消息先動。附觸發的那則新聞，或那段相對強弱的變化。
3. **因果鏈**：需求來源 → 瓶頸 → 受益環節 → 公司。
   - 每一環附出處。
   - 每家公司附「題材營收占比」（不知道就標不知道）和「領漲 / 補漲」。
4. **第二層效應**：外溢、排擠、轉嫁、意外受害。
5. **論點**（多個，每個都可以被推翻）
   - 寫法：一句話說法 + 時間點（現在放量或 roadmap）+ 賺什麼錢。
   - 狀態：加強、削弱、被推翻、待確認。
   - 證據：依等級排列（管理層 / 財報 / 訂單 > 媒體 > KOL > 未證實）。新聞在這裡掛上來，標「加強 / 削弱 / 無關」。
   - 推翻條件（基本面）。
6. **階段**：每一階段都要有可量的訊號，AI 只能依訊號判斷，並列出依據。
   - 萌芽：題材先走、預期投射。
   - 確認：bottom-up 證據出現。
   - 擴散：補漲股增加、相關報導變多。
   - 射出：脫離基本面。
   - 鈍化：利多推不上、新高攻不上。
7. **市場怎麼回應**：籃子相對強弱、領漲股 vs 補漲股、對利多的反應。這裡才用到股價。
8. **交易上的下車訊號**：破線、新高攻不上。跟第 5 點的論點推翻分開。
9. **其他人怎麼說**：KOL 的看法和時間點。看法也記進帳本，之後一起打分。

## 對 spec 的影響（待使用者確認後改）

- 新增核心物件：**Theme**（題材，已是 Entity 的一種）底下掛 **Thesis**（論點）。新聞對論點的關係是 **Evidence**（加強 / 削弱 / 無關 + 證據等級）。預測掛在論點上。
- **供應鏈因果鏈**要從「v2 關係圖」提前，v1 先做成文字清單加營收占比，不做圖。
- **新增一個觸發**：族群相對轉強，但沒有對應的敘事 → 提示「市場在動，原因不明」。
- **盲判的對象**從「這則新聞對某檔股票是多是空」改成「這則新聞加強還是削弱哪個論點」。股價對答案保留，但掛在論點和階段上。
- **Golden set 擴充**：除了新聞的重要度，還要能評估以下幾件事，用來調 system prompt、context 結構，以及之後的多新聞 agentic 架構：
  - 新聞 → 論點的關聯
  - 證據等級
  - 階段判斷
  - 因果鏈有沒有編造
- **最大的風險**：AI 生成的因果鏈和第二層效應聽起來合理，但可能是編的。對策：
  - 每一環都要有出處，沒有的就標「AI 推論」。
  - 營收占比不准 AI 估，只能引用來源。
  - 階段只能依可量訊號判斷。
